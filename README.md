# DevTrack

**DevTrack** — настольное приложение для управления IT-проектами, задачами и техническими заметками, а также для учёта затраченного рабочего времени.

Приложение разработано на Python с использованием PyQt6 и SQLite. Для взаимодействия с базой данных применяется SQLAlchemy.

## Возможности

DevTrack предоставляет следующие возможности:

- **Управление проектами:** создание, редактирование, просмотр и удаление проектов.
- **Управление задачами:** добавление задач к проектам, изменение их статусов и приоритетов, указание сроков выполнения.
- **Технические заметки:** создание, редактирование и удаление заметок, возможность связывать их с проектами.
- **Учёт рабочего времени:** запуск и остановка рабочих сессий, сохранение затраченного времени.
- **Статистика:** отображение количества проектов и задач, числа завершённых задач, общего прогресса и затраченного времени.
- **Импорт и экспорт:** поддержка импорта и экспорта данных в формате CSV, сохранение заметок в TXT.

## Архитектура проекта

Проект имеет модульную архитектуру. Основные части приложения разделены по назначению, что упрощает поддержку и дальнейшее развитие программы.

### 1. Графический интерфейс (`ui/`)

В этой директории находятся классы, отвечающие за отображение интерфейса и взаимодействие с пользователем.

- `main_window.py` — главное окно приложения, боковая панель навигации и переключение страниц.
- `dashboard.py` — главная страница с общей информацией.
- `projects_page.py` — страница управления проектами.
- `tasks_page.py` — страница управления задачами.
- `notes_page.py` — страница технических заметок.
- `timer_page.py` — страница учёта рабочего времени.
- `statistics_page.py` — страница статистики.

### 2. Работа с базой данных (`database/`)

Директория содержит компоненты для подключения к базе данных и описания её структуры.

- `database.py` — создание подключения к SQLite, настройка сессий SQLAlchemy и инициализация базы данных.
- `models.py` — описание моделей данных: `Project`, `Task`, `Note`, `TimeSession`, `Tag`.

Модели связаны между собой с помощью отношений SQLAlchemy и внешних ключей.

### 3. Бизнес-логика (`services/`)

В этой директории реализованы основные операции приложения. Сервисы отделяют обработку данных от графического интерфейса.

- `project_service.py` — операции с проектами.
- `task_service.py` — операции с задачами, поиск и фильтрация.
- `note_service.py` — операции с заметками.
- `timer_service.py` — создание и завершение рабочих сессий, расчёт затраченного времени.
- `statistics_service.py` — получение данных для статистики.

### 4. Дополнительные инструменты (`utils/`)

- `csv_manager.py` — функции импорта и экспорта данных в CSV.

## Установка и запуск

Для запуска приложения из исходного кода необходимо установить Python и зависимости проекта.

### 1. Клонирование проекта

```bash
git clone <ссылка-на-репозиторий>
cd DevTrack
```

Если проект уже скачан, достаточно перейти в его директорию.

### 2. Создание виртуального окружения

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
python main.py
```

На macOS и Linux при необходимости следует использовать:

```bash
python3 main.py
```

При первом запуске приложение автоматически создаёт директорию `data` и базу данных SQLite.

## Сборка приложения

Для создания исполняемой версии используется PyInstaller.

Установка:

```bash
pip install pyinstaller
```

### Windows

```bash
pyinstaller --noconfirm --windowed --name DevTrack --collect-all PyQt6 main.py
```

После завершения сборки исполняемый файл будет находиться в директории `dist/`.

### macOS

```bash
pyinstaller --noconfirm --windowed --name DevTrack --collect-all PyQt6 main.py
```

Результатом сборки будет приложение для macOS.

### Linux

```bash
pyinstaller --noconfirm --windowed --name DevTrack --collect-all PyQt6 main.py
```

**Важно:** PyInstaller не выполняет кросс-компиляцию. Для получения версии под Windows сборку необходимо выполнять в Windows, под macOS — в macOS, под Linux — в Linux.

## Хранение данных

Для хранения информации используется SQLite. База данных располагается в директории `data/` и называется `devtrack.db`.

В базе данных хранятся следующие сущности:

- **Project** — информация о проектах.
- **Task** — задачи, связанные с проектами.
- **Note** — технические заметки.
- **TimeSession** — рабочие сессии и затраченное время.
- **Tag** — теги.

Связи между сущностями позволяют хранить задачи и заметки в контексте соответствующих проектов, а также учитывать рабочее время.
